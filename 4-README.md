# DEEP//SHIFT
A polished browser-first VR mining game prototype. Explore a procedurally built Europa shaft, scan mineral signatures, mine cobalt glass and void opal with a plasma cutter, and complete a 12kg extraction contract.

## Controls
- WASD move
- Mouse look
- Click plasma cutter
- E scan
- Shift boost

Built with Three.js. The first-person build is playable on desktop; WebXR headset mode is the next production step.
